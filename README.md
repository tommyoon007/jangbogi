# 장보기 (jangbogi)

영수증으로 장보기 기록을 남기고, 품목별 **가격 비교**와 **기간별 지출 정리**, **살 물품 목록**을 한 화면에서 보는 휴대폰 앱(PWA)입니다.
빌드 없이 HTML·CSS·자바스크립트만으로 만들어져 GitHub Pages에서 그대로 열립니다.

- 앱 주소: https://tommyoon007.github.io/jangbogi/
- 휴대폰 크롬에서 오른쪽 위 ⋮ → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

## 화면

| 탭 | 하는 일 |
| --- | --- |
| 장볼목록 | 살 물품 체크리스트(품목마다 지난 구매가·최저가·구매처 표시), 자주 사는 **단골 품목**에서 ‘다 떨어짐’ 한 번으로 목록에 담기 |
| 가격비교 | 품목 검색·분류별 보기, 값이 어떻게 변했는지 그래프, 가게별 최저가 |
| 기간정리 | 이번 주 / 이번 달 / 지난 달 / 전체 지출, 가게별·분류별 비중, 월별 추이 |
| 영수증 | 영수증 목록(날짜·가게·품목·할인·낸 금액), 앱에서 직접 넣기·고치기·지우기 |

## 자료가 저장되는 곳

1. `data/receipts.json` — 기본 영수증 자료. 형식은 아래와 같고, 같은 형식으로 항목을 추가해 `main`에 올리면 앱에 바로 나타납니다.
   (채팅으로 영수증 사진을 보내면 모아가 이 파일에 정리해 넣습니다.)
2. 휴대폰 저장 공간(`localStorage`) — 앱에서 체크한 것, 직접 넣거나 고친 영수증. 인터넷이 없어도 유지됩니다.

```json
{
  "receipts": [
    {
      "id": "r-2026-11-23-1",
      "date": "2026-11-23",
      "store": "이마트 강일점",
      "items": [
        { "name": "서울우유 1L", "category": "유제품/음료", "qty": 1, "price": 2910 }
      ],
      "discount": 0,
      "total": 2910,
      "memo": "",
      "sample": false
    }
  ]
}
```

- `category`는 `채소/과일`, `정육/수산`, `유제품/음료`, `식품`, `생필품`, `기타` 중 하나입니다.
- `total`을 적지 않으면 `수량 × 값` 합계에서 할인을 뺀 값으로 계산합니다.
- `sample: true`인 영수증은 ‘샘플 데이터’로, 앱의 **더보기 → 샘플 비우기**에서 숨길 수 있습니다.

## 파일

```
index.html   화면 뼈대
app.js       화면 그리기·계산·저장
styles.css   모바일 우선 스타일
manifest.json / sw.js / icon*.png   홈 화면 설치·오프라인용
data/receipts.json                  기본 영수증 자료
```
